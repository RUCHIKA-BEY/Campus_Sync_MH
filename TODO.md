# CampusSync frontend conversion

- [x] Faithful vanilla HTML5 recreation of the existing CampusSync pages, navigation, layouts, dashboard views, content structure, and supplied imagery.
- [x] Responsive CSS3 design system using reusable CSS variables, modern flexbox/grid, and the existing warm colour palette without Tailwind.
- [x] Vanilla JavaScript event discovery with browsing, searching, filtering, event detail, and create-event interactions.
- [x] Timetable interface preserving weekly schedule views and frontend conflict-context messaging.
- [x] Registration flows with browser-local registration state, ticket presentation, cancellation, and OD-friendly states.
- [x] Clubs directory with searchable club cards and preserved discovery experience.
- [x] Notifications drawer with simulated unread/read states.
- [x] Role-switching controls for Student, Organizer, DSA, and Admin frontend views.
- [x] Persistent footer and evaluation console with responsive behavior.
- [ ] Backend, authentication, payments, and persistence remain intentionally out of scope for this frontend-only conversion.
